What you can do on each site

Every site sites.b keeps is left in a state its owner can carry on without waiting for an agent. Each one is static files in site/ on the dev branch: edit them on GitHub in the browser, or ask your own Claude (each site's /agents/ page says how). The checks run on every change and publish within minutes.
